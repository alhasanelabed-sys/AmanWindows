# أمان Windows — الإصدار 1.0

أداة محلية بواجهة عربية ومصدر متاح للمراجعة لفحص إعدادات الحماية ومراجعة مؤشرات أمنية، مع ثلاثة إصلاحات محددة. تعمل باستخدام Windows PowerShell 5.1 الموجود في Windows 10 و11، ولا تحتاج تثبيت Python أو تنزيل مكتبات.

## التشغيل

1. نزّل الحزمة ZIP. إذا ظهرت خانة **إلغاء الحظر / Unblock** في خصائص الحزمة، استخدمها لهذه الحزمة قبل استخراجها، حتى يسمح Windows بتشغيل النصوص المحلية غير الموقعة.
2. استخرج جميع الملفات إلى مجلد واحد؛ لا تشغّلها من داخل ZIP.
3. افتح **Start.cmd** لتشغيل الواجهة. يبدأ فحص الإعدادات فقط، دون إصلاحات تلقائية.
4. اضغط **تشغيل كمسؤول** عند الحاجة لقراءة سجلات الأمان أو إجراء إصلاح. سيظهر طلب UAC العادي.
5. راجع النتائج والأدلة. اختر إجراءً واقرأ أثره قبل الموافقة على تطبيقه. يعيد البرنامج الفحص بعد نجاح الإجراء.

لفحص نصي فقط، افتح **Scan.cmd**، أو من Windows PowerShell داخل مجلد البرنامج:

```powershell
powershell.exe -NoLogo -NoProfile -ExecutionPolicy RemoteSigned -File .\Aman.ps1 -Console
```

ملفات التشغيل تستخدم سياسة RemoteSigned لهذه العملية فقط؛ لا تغير سياسة النظام. إذا كانت سياسة المؤسسة تمنع النصوص، اطلب من مسؤول الجهاز مراجعة المصدر، ولا تعطل الحماية أو تتجاوز سياسة المؤسسة. النصوص غير موقعة رقميًا.

## ما يجمعه الفحص

| الفحص | البيانات والحدود |
| --- | --- |
| النظام | اسم النظام وإصداره ورقم البناء وUBR. |
| Defender | الوضع النشط، الحماية الفورية، عمر التعريفات، والتهديدات التي يبلغ عنها Defender؛ لا يفحص محركات حماية الشركات الأخرى. |
| الجدار الناري | الحالة الفعلية لملفات Domain وPrivate وPublic، بما فيها السياسات المدمجة. لا يحلل كل قاعدة سماح. |
| الوصول البعيد | تفعيل RDP واشتراط NLA إن أتاح موفر Windows قراءة حالتها. |
| SMB1 وUAC | حالة ميزة SMB1 القديمة وإعداد UAC؛ حالة تثبيت SMB1 لا تثبت تشغيل خادمها أو التعرض للإنترنت. |
| الشبكة | لقطة TCP وعناوين الأطراف والعمليات، ومنافذ UDP المحلية. مطابقة العملية قد تتأثر بخروجها أو إعادة استخدام PID؛ المسار الفارغ يعني أنه غير معروف. |
| بدء التشغيل | جرد جزئي من Win32_StartupCommand، دون تنفيذ أي أمر منه. لا يشمل كل المهام والخدمات وآليات الاستمرار. |
| الدخول | آخر 24 ساعة، بحد أقصى 2000 حدث من 4624 و4625. يعرض دخول RDP من النوع 10 ومحاولات الدخول الفاشلة المتكررة من المصدر نفسه عند بلوغ 10 محاولات. |
| التحديثات | جرد Get-HotFix المتاح؛ لا يمثل قائمة كاملة للتصحيحات أو كشفًا لثغرات التطبيقات. |

الحالة «غير محسومة» تعني تعذر تأكيد الفحص أو نقص بياناته. تكرر الدخول الفاشل قد ينتج عن أخطاء كلمات المرور أو بيانات قديمة. غياب أحداث الدخول قد ينتج عن تعطيل التدقيق أو مسح السجل أو استبداله، ولا يثبت السلامة. عناوين IP لا تثبت الهوية الشخصية للمهاجم، والاتصال أو المنفذ المفتوح لا يثبت اختراقًا.

## الإصلاحات المتاحة

- **تفعيل الجدار الناري:** يفعّل الملفات المحلية الثلاثة فقط؛ لا يغير قواعد السماح أو الحظر. قد يؤثر في الوصول الوارد إلى الجهاز. يتحقق من الحالة الفعلية بعد التغيير؛ إن فرضت سياسة المؤسسة حالة أخرى، يبلغ عن فشل التحقق.
- **تفعيل حماية Defender الفورية:** يعمل فقط عندما يكون Defender هو المحرك النشط في وضع Normal. لا يغيّر الاستثناءات أو إعدادات إرسال العينات أو الحماية من العبث، ولا يتجاوز سياسة المؤسسة.
- **اشتراط NLA لسطح المكتب البعيد:** لا يفعّل RDP ولا يعيد تشغيل خدمته. قد يمنع العملاء القدامى من إعادة الاتصال. يتوقف إذا كان هذا الإعداد مدارًا بنهج المؤسسة.

يحفظ كل إجراء الحالة السابقة في ملف JSON **قبل** تغيير النظام. إذا تعذر حفظها، لا يبدأ التغيير. نتيجة Failed قد تعني تغييرًا جزئيًا أو فشل التحقق؛ راجع ملف التغيير والحالة الحالية ولا تفترض عدم تغير شيء.

زرّا فحص Defender السريع والكامل يستدعيان محرك Windows الأصلي؛ قد يعزل Defender ملفات وفق إعداداته. لا تعتبر عملية إرسال طلب الفحص إثباتًا لانتهائه أو لخلو الجهاز. راجع حالته وسجل الحماية في أمان Windows. زر تحديث التعريفات يستخدم مصادر التحديث المهيأة في Windows، وقد يحتاج اتصالًا بالشبكة. فتح Windows Update يساعدك على تثبيت التصحيحات؛ الأداة لا تثبت تحديثات النظام أو التطبيقات تلقائيًا.

## التقارير والاستعادة

التقارير الافتراضية في:

```text
%LOCALAPPDATA%\AmanWindows\Reports
```

كل فحص يحفظ تقرير HTML يمكن فتحه دون اتصال وملف JSON بالأدلة. سجلات الإصلاح في المجلد الفرعي **Receipts**. تحتوي التقارير على أسماء مستخدمين ومسارات وأوامر بدء تشغيل وعناوين شبكة؛ لا ترفعها علنًا. لا يرفع التطبيق التقارير أو الملفات بنفسه. قد يستخدم Defender الحماية السحابية وإرسال العينات وفق إعدادات Windows الحالية؛ لا يغيّر البرنامج تلك الإعدادات.

إذا احتجت استعادة إعداد سابق، افتح Windows PowerShell **كمسؤول** داخل مجلد البرنامج، واستبدل المسار أدناه بمسار سجل التغيير الصحيح:

```powershell
powershell.exe -NoLogo -NoProfile -ExecutionPolicy RemoteSigned -File .\Restore.ps1 -ReceiptPath 'C:\path\to\change-file.json'
```

تطلب الاستعادة موافقة صريحة، وقد تعيد إعدادًا أقل حماية. تتحقق من صيغة الملف واسم الجهاز وقيم الإعداد وقائمة الإجراءات. تتوقف عند رصد إعدادات تغيرت إلى قيمة لا تطابق الحالة السابقة أو القيمة التي طبقها البرنامج. لا ينفّذ البرنامج أوامر من ملف الاستعادة. لا توجد استعادة تلقائية.

## التحقق وحدود النسخة

تم إعداد اختبارات مستقلة للبيانات الناقصة، وتفسير الأحداث، ومنع حقن HTML، وحفظ العربية، وقائمة الإصلاحات، وعدم التغيير في WhatIf، والتحقق من ملفات الاستعادة، وتسلسل حفظ الإعداد السابق قبل التغيير. اختبارات الإصلاح تستخدم بدائل محلية للأوامر ولا تغير جهاز الاختبار.

يمكن تشغيلها من Windows PowerShell داخل مجلد البرنامج:

```powershell
powershell.exe -NoLogo -NoProfile -ExecutionPolicy RemoteSigned -File .\tests\Test-Guard.ps1
```

تم تنفيذ الاختبارات المحمولة وفحص صياغة النصوص في بيئة Linux باستخدام PowerShell 7.4.6. **لم يتوفر جهاز Windows فعلي لاختبار الواجهة وأوامر Windows الحية؛ لذلك يظل هذا الجزء غير متحقق عمليًا هنا.** اقرأ المصدر واختبر البرنامج على جهاز تجريبي قبل الاعتماد على إصلاحاته على جهاز عمل مهم.

هذه أداة مساعدة لفحص الحالة وليست محرك مكافحة فيروسات جديدًا أو مراقبة مستمرة أو ماسح CVE شاملًا. لا تسد جميع الثغرات ولا تكشف كل اختراق ولا تثبت اسم المهاجم. يلزم تحديث Windows والتطبيقات واستخدام محرك حماية موثوق ومراجعة أي مؤشرات غير متوقعة.
