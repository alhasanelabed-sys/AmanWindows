# أمان Windows

برنامج محلي بواجهة عربية لمراجعة إعدادات الحماية ومؤشرات أمنية على Windows 10 و11، مع إصلاحات محددة تتطلب موافقة المستخدم.

## تنزيل البرنامج وفتحه

1. افتح [حزمة التشغيل ZIP](releases/AmanWindows-1.0.0.zip)، ثم اضغط زر **Download raw file** لتنزيلها.
2. من خصائص ZIP، استخدم **Unblock / إلغاء الحظر** إن ظهرت هذه الخانة، ثم استخرج جميع الملفات.
3. افتح **Start.cmd** داخل مجلد **AmanWindows** المستخرج. لا تشغّل البرنامج من داخل ZIP.
4. يبدأ فحص الإعدادات دون إصلاح تلقائي. زر **تشغيل كمسؤول** يفتح طلب UAC عند الحاجة.

## حدود النسخة

اجتاز البرنامج 27 اختبارًا محمولًا في Linux باستخدام PowerShell 7.4.6. الواجهة وأوامر الحماية الحية على Windows PowerShell 5.1 **لم تُختبر على جهاز Windows فعلي** في بيئة إعداد النسخة.

هذه أداة فحص حالة وإعدادات، وليست كشفًا شاملًا لكل الثغرات أو كل الاختراقات. لا تحدد هوية شخص من عنوان IP. التقارير تبقى محلية ولا تُرفع إلى GitHub تلقائيًا.
